# ADR 0023 — Dedicated runtime security test project

Status: superseded by ADR 0026 (2026-07); orchestration later standardized on
Aspire in ADR 0029. Historical only; do not follow.

The need for real migration/OIDC/tenant-boundary smoke remains accepted, but it
is implemented as a focused CI/AppHost workflow rather than a dedicated broad
runtime test project.
